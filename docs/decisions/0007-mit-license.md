# 0007. Packages are MIT licensed

**Status:** decided, 2026-09-28.

## Context

The repository is public so the source and Storybook can be read, and the packages are
meant to be installed by apps other than the ones they were extracted from, commercial ones
included.

## Decision

[MIT](../../LICENSE), for the repository and every published package. Each package ships its
own copy of the file, listed in its `files`.
