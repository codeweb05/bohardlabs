# 0005. The DataTable feature backlog lives in this repo

**Status:** decided, 2026-08-28.

## Context

The backlog was written in `skipwash-admin/docs/` while the table was still an app
component. It describes the library, not the app, and the code is here now.

## Decision

It lives at [`../packages/datatable/roadmap.md`](../packages/datatable/roadmap.md). The
copy in `skipwash-admin/docs/` is stale from this point on; delete it when the app switches
to the package.

That file is the feature backlog for one package. Where that backlog stands next to
everything else in the repo is on [`../roadmap.md`](../roadmap.md).
