# 0009. Public terms are PolyForm Noncommercial

**Status:** decided, 2026-08-29.

## Context

The repository is public so the source and Storybook can be read. MIT, Apache, and GPL
all allow commercial use. The point of publishing the source is not to give companies a
free product.

## Decision

The public copy is licensed under [PolyForm Noncommercial 1.0.0](../../LICENSE). Personal,
research, hobby, and qualifying non-profit or government use is allowed. Using the software
in a business, a paid product, or any other commercial purpose needs a separate paid
license from the copyright holder.

This is not an OSI open-source license. npm and GitHub will show it as source-available
and non-commercial.

## Follow-ups

A paid commercial license is a contract, not this file. Until one exists, commercial use
is simply not granted.
